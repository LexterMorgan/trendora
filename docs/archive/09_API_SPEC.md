# 09 — API spec

Status: Phase 0 placeholder. FastAPI is not implemented.

## Role

FastAPI sits between PostgreSQL analytics results and Streamlit (and any future clients).

It should expose **read models** of Python-computed results, not raw connector dumps and not ad-hoc SQL.

## Likely resource groups (later)

- health
- markets / topics
- content snapshots
- kpi series
- forecasts / anomalies
- explanations (if AI enabled)

## Constraints

- No unrestricted query endpoint for an LLM.
- Authn/z for any non-local deployment (not designed yet).
- Pagination and `collected_at` filters from day one of implementation.
- OpenAPI generated by FastAPI will be the contract.

## Not started

Path list, Pydantic models, versioning (`/v1`), rate limits.
